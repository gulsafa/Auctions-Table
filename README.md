# Auctions Table

A simple and responsive **front-end project** displaying an auctions table built with HTML, CSS, and JavaScript.  
This project focuses on practicing table layouts, styling, interactivity, and clean UI design.

---

## 🌍 Live Demo
🔗 [View Project](https://gulsafa.github.io/Auctions-Table/)

---

## 📂 Project Structure
- `index.html` → Main file with table layout  
- `style.css` → Styling for the table and design  
- `script.js` → JavaScript for interactivity  
- `dashboard.html` → Dashboard where users can see uploads, sold, and winner items  
- `img/` → Folder containing images used in the website  

---

## 🎯 Features
- Clean and modern table layout  
- Interactive elements with JavaScript  
- Dashboard for tracking items  
- Beginner-friendly project structure
